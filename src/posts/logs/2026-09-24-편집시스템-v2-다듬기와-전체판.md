문제: v1은 방향은 맞았지만 참고 리포트보다 글자가 크고 행간이 넓었다. 파란 소제목이 한 쪽에 세 개씩 있어
모든 전환이 같은 무게였고, 리드 전체가 Bold라 헤드라인과 경쟁했다.

선택지: ① 레이아웃 재설계 ② 조판·밀도·위계만 조정

결정: ②. 검증된 구성은 건드리지 않고 바꾸는 변수를 줄였다.

변경:
- 본문 8.6pt/행간 1.72 → 7.9pt/1.52, 헤드라인 17.5 → 15.5pt, 세션 라벨 12.5pt → 9pt 회색
- 리드: 전체 Bold → Regular + 핵심 숫자만 Bold
- 파란 소제목은 쪽당 1개, 나머지는 검정 Bold 소제목 또는 문단 첫 어구 Bold
- 액센트 #0a6bb3(웹 블루) → #168fa8(청록), 머리글 세션명 회색, 왼쪽 1.6mm 시리즈 세로선
- 그림 4: 큰 숫자 3개 → 작은 3줄 식 + 레버리지 막대(KB 13.8 / 삼성전자 1.31배)

결과: ../design-system/reference/비교_삼성증권p2_vs_v2.png (참고 리포트와 밀도·색 사용량 비슷)
전체판: 쪽 유형을 D 표지 / A 오프너 / B / A' / B / C 데이터 / 부록으로 순환해 같은 틀 반복을 피함.
검증: 원본 숫자 토큰 189개 대조 누락 0, 산출물 파일명 5개·출처 보존, 7쪽 모두 넘침 없음.
